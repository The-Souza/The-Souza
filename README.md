## Projetos

### BillWise Dashboard — Gestão Financeira Pessoal

Aplicação fullstack para gerenciamento de contas, orçamentos, recorrências e analytics. Reescrita completa do Account Management com arquitetura moderna e stack integrada.

**Stack:** Next.js 16 (App Router) · TypeScript · Prisma 7 · PostgreSQL · Supabase Auth · Tailwind CSS v4 · React Hook Form + Zod · SWR · Recharts · Vitest

**Destaques:**

- SSR com Server Components e mutations via Server Actions — sem camada de API separada
- ORM com Prisma: queries tipadas, migrations versionadas, transações atômicas
- RBAC com roles `user` e `admin`, guards server-side em toda rota protegida
- Zod em toda boundary (forms, server actions, API routes)
- Testes escritos antes da implementação (Vitest)
- Features: dashboard financeiro, contas com parcelamento, orçamentos por categoria, analytics, notificações, recorrências com cron job, área admin

**Status:** Em desenvolvimento · Deploy previsto em breve  
**Repositório:** [github.com/The-Souza/billwise-dashboard](https://github.com/The-Souza/billwise-dashboard)

### Consulta NF-e / CT-e — Automação Desktop

Aplicativo desktop para consultar associações NF-e → CT-e e fazer upload de canhotos via API interna. Desenvolvido para uso em transportadora — sem necessidade de browser ou cópia manual de tokens.

**Stack:** Python · CustomTkinter · Tesseract OCR · Windows Credential Manager · PyInstaller

**Destaques:**

- Login automático, busca por intervalo de NF-e, exportação para Excel
- OCR para detectar número de NF-e em imagens de canhotos e renomear automaticamente
- Upload de canhotos com validação de status (`PENDENTE`)
- Credenciais salvas com segurança via keyring
- Distribuído como `.exe` — sem necessidade de Python na máquina de destino
- Configurável via `.env` para qualquer empresa com API compatível

**Repositório:** [github.com/The-Souza/consulta-nfe-cte](https://github.com/The-Souza/consulta-nfe-cte)
